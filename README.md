# 📊 Executive Sales Dashboard — Excel

## Overview
Interactive Excel dashboard analyzing product sales data across 
stores, regions, salespeople, and payment methods.

## Features
- KPI Cards with YoY % change & sparklines
- Dynamic Timeline & Store slicers
- 6+ chart types including radial bubble, donut, lollipop
- Dark theme premium design

## Tools Used
- Microsoft Excel
- Pivot Tables & Pivot Charts
- Slicers & Timeline filters
